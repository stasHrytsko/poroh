# Порог

## Единый мессенджер и профиль человека

Порог показывает только сервисы, подключённые пользователем. Основной объект — человек, а не отдельный аккаунт мессенджера.

Раздел «Люди» показывает тех, с кем пользователь общался за последний месяц. Старые контакты остаются в поиске. Поиск среди знакомых и поиск в интернете являются отдельными действиями. Результат интернет-поиска не считается знакомым и не создаёт контакт автоматически.

Если один человек найден в нескольких подключённых сервисах, агент предлагает объединение. Пользователь подтверждает его кнопкой либо поручает агенту фразой «объедини аккаунты Алины». Ошибочное объединение должно отменяться.

В профиле человека доступна единая хронологическая переписка. У каждого сообщения виден сервис-источник. Историю можно фильтровать по времени. При ответе Порог выбирает сервис последнего входящего сообщения; пользователь может выбрать другой из подключённых для этого человека.

Профиль содержит четыре блока: переписка, коммиты, важные даты и заметки. Коммит — подтверждённая договорённость. Агент определяет кандидата по контрольным формулировкам, дате и согласию обеих сторон. Неоднозначный кандидат требует подтверждения пользователя. Перенос создаёт новую версию коммита и сохраняет историю.

Важные даты хранятся отдельно от коммитов. Дата встречи относится к коммиту, день рождения — к профилю человека. Заметки добавляет и удаляет только пользователь; агент не создаёт их сам.
