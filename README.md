# Порог

Кликабельный прототип личного приложения между пользователем и интернетом.

## Что можно попробовать

- Главная сводка и переключение доступности.
- Личные сообщения: ответ вручную или подготовка ответа демо-агентом.
- Разбор подозрительной просьбы перевести деньги.
- Конечный выпуск каналов: суть, оригинал, проверка утверждений.
- Сохранение договорённостей и история действий.
- Настройки защиты и сброс демонстрации.

## Запуск

Приложение написано на обычных HTML, CSS и JavaScript. Установка зависимостей и сборка не требуются.

Из корня репозитория:

```bash
python3 -m http.server 8080 --directory dist
```

Откройте http://localhost:8080. Для доступа с телефона в той же сети используйте локальный IP компьютера и порт 8080.

Можно также открыть `dist/index.html` напрямую, но локальное сохранение состояния зависит от ограничений браузера для файлов.

## Файлы

- `dist/index.html` — точка входа и метаданные.
- `dist/styles.css` — адаптивный интерфейс.
- `dist/app.js` — экраны, сценарии и локальное состояние.

## Ограничения прототипа

Telegram не подключён. Все сообщения, источники и статистика демонстрационные. Реальных отправок, платежей, звонков, системных напоминаний и проверки внешних ссылок нет. Агент отвечает по сценариям, без подключения к LLM. Настройки и введённые в демонстрацию ответы хранятся в localStorage этого браузера; сброс доступен в настройках. Не вводите реальные секреты и чувствительные данные.

Шрифт Manrope загружается через Google Fonts; при отсутствии сети используется системный шрифт. WebMCP регистрируется только в поддерживающих его браузерах.

## Проверка

```bash
node --check dist/app.js
```

Для отдельного статического хостинга укажите `dist` как публикуемую директорию. Приватные настройки исходной публикации Sites в этот репозиторий не включены.
